# Mobile-Native E2E Testing Instructions

1. Identify critical mobile journeys and platform-specific capabilities.
2. Map lifecycle, permissions, deep links, interruptions, connectivity, and OS behavior.
3. Select representative simulators, emulators, and physical devices by risk.
4. Define isolated data, app reset, installation, backend, and device-lab setup.
5. Automate semantic user interactions and capture native diagnostics.
6. Validate offline, background, rotation, notification, and permission transitions.
7. Connect smoke and release suites to the mobile delivery pipeline.

Use physical devices when hardware, rendering, sensors, performance, or platform behavior cannot be represented reliably by simulators.
