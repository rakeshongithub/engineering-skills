# Frontend Backend Contract Testing Instructions

1. Inventory frontend consumers, endpoints, events, and critical fields.
2. Capture meaningful requests, responses, errors, permissions, and edge cases.
3. Define contracts around consumer needs rather than provider implementation.
4. Verify provider behavior against consumer expectations and schemas.
5. Test nullability, enum evolution, extra fields, errors, and authorization.
6. Run contracts in consumer and provider pipelines.
7. Escalate breaking changes with migration and deprecation guidance.

Use contract tests for compatibility and E2E tests for complete user outcomes.
