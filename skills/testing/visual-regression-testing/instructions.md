# Visual Regression Testing Instructions

1. Identify high-value visual contracts and meaningful states.
2. Control fonts, data, time, animations, viewport, theme, locale, and browser conditions.
3. Capture representative component, page, and journey states.
4. Compare with appropriate thresholds and inspect differences semantically.
5. Classify changes as intended, regression, environment noise, or baseline defect.
6. Approve or update baselines with ownership and rationale.
7. Track recurring failures and improve rendering controls.

Mask only truly dynamic regions; excessive masking hides regressions.
