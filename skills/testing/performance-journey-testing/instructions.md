# Performance Journey Testing Instructions

1. Select journeys by business impact, frequency, and performance sensitivity.
2. Define realistic personas, data volumes, devices, networks, and concurrency.
3. Instrument journey start, milestones, completion, errors, and resource use.
4. Capture baseline percentile and failure measurements.
5. Run normal, degraded, peak, and recovery scenarios.
6. Correlate browser, API, database, and infrastructure evidence.
7. Set budgets and regression gates tied to user outcomes.

Separate page performance, interaction latency, capacity, and journey completion reliability.
