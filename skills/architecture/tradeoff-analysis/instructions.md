# Tradeoff Analysis - Step-by-Step Instructions

## Overview

This skill guides you through systematically comparing architectural alternatives to support informed decision-making.

## Step-by-Step Workflow

### Step 1: Define Alternatives (30 minutes)

**Actions:**
1. List all viable options (2-5 alternatives)
2. For each alternative, document:
   - Name and brief description
   - Key characteristics
   - Rough effort estimate
3. Eliminate obviously infeasible options

**Outputs:**
- List of 2-5 viable alternatives with descriptions

### Step 2: Identify Evaluation Criteria (30-45 minutes)

**Actions:**
1. List all relevant quality attributes:
   - Performance
   - Scalability
   - Reliability
   - Security
   - Maintainability
   - Cost
   - Time to implement
   - Team expertise
2. Assign weights (High/Medium/Low)
3. Validate criteria with stakeholders

**Outputs:**
- Weighted list of evaluation criteria

### Step 3: Score Each Alternative (1-2 hours)

**Actions:**
1. For each criterion, score each alternative (1-10)
2. Provide brief justification for each score
3. Document assumptions
4. Validate scoring with team members

**Outputs:**
- Scored evaluation for each alternative

### Step 4: Create Tradeoff Matrix (30 minutes)

**Actions:**
1. Create comparison table
2. Include all criteria and scores
3. Calculate weighted scores if applicable
4. Highlight strengths and weaknesses

**Outputs:**
- Complete tradeoff matrix

### Step 5: Analyze Tradeoffs (1 hour)

**Actions:**
1. For each alternative, identify:
   - Strengths (what it does well)
   - Weaknesses (limitations)
   - Key tradeoffs (what you gain vs. what you give up)
2. Consider context and constraints
3. Assess risks

**Outputs:**
- Tradeoff analysis for each alternative

### Step 6: Develop Recommendation (30-45 minutes)

**Actions:**
1. Identify top option(s)
2. Articulate rationale
3. Explain key tradeoffs being accepted
4. Consider alternative if constraints change

**Outputs:**
- Clear recommendation with rationale

### Step 7: Document and Present (1 hour)

**Actions:**
1. Write executive summary (1 page)
2. Document detailed analysis
3. Create visual comparison (table or chart)
4. Prepare presentation for stakeholders

**Outputs:**
- Complete tradeoff analysis document
- Presentation deck

## Scoring Guidelines

**1-3 (Poor):**
- Does not meet requirements
- Significant limitations
- High risk or cost

**4-6 (Acceptable):**
- Meets minimum requirements
- Some limitations
- Moderate risk or cost

**7-8 (Good):**
- Exceeds requirements
- Minor limitations
- Low risk or cost

**9-10 (Excellent):**
- Far exceeds requirements
- No significant limitations
- Very low risk or cost

## Tips for Success

- **Be objective**: Base scores on evidence, not preference
- **Be consistent**: Use the same scale for all alternatives
- **Be specific**: Provide justification for scores
- **Be realistic**: Consider constraints and context
- **Involve the team**: Validate scoring with others
- **Focus on high-weight criteria**: Don't get lost in low-value details

## Common Pitfalls to Avoid

- Scoring to favor a preferred option (confirmation bias)
- Using too many criteria (analysis paralysis)
- Not weighting criteria (treating all as equal)
- Subjective scoring without justification
- Ignoring constraints (recommending infeasible options)
- Not making a clear recommendation
