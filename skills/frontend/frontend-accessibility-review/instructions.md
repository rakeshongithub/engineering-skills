# Frontend Accessibility Review Instructions

1. Select critical tasks and identify supported browsers, assistive technologies, and input methods.
2. Inspect semantic structure, headings, landmarks, names, roles, values, and document order.
3. Complete each task with keyboard only and verify focus visibility, order, trapping, and restoration.
4. Test zoom, contrast, text resizing, reduced motion, responsive states, and dynamic announcements.
5. Review forms, errors, dialogs, tables, loading states, and permission changes.
6. Run automated checks, then manually verify representative flows with assistive technology.
7. Record impact, reproduction steps, criterion, remediation owner, and regression coverage.

Block barriers that prevent a critical task; do not rank issues by automated scanner count alone.
