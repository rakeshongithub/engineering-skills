# Responsive Design Instructions

1. Identify the primary task, content priority, supported viewports, input methods, and zoom expectations.
2. Design the narrowest usable layout before expanding to larger widths.
3. Define fluid sizing, container behavior, wrapping, reflow, overflow, and breakpoint rules.
4. Adapt navigation, dialogs, tables, forms, and actions for touch and keyboard use.
5. Test long labels, localization, text resizing, reduced motion, and orientation changes.
6. Verify loading and error states do not change dimensions unexpectedly.
7. Produce responsive rules, representative viewport cases, and unresolved exceptions.

Treat breakpoints as responses to content failure, not as device categories.
