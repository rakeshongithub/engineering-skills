# Responsive Design Examples

## Checkout Form

On mobile, stack fields and keep the primary action visible without covering validation errors. On desktop, use a constrained two-column layout. Preserve keyboard order, support zoom, and allow long address content to wrap.

## Analytics Dashboard

At narrow widths, prioritize the key metric and allow secondary charts to scroll or move below the primary task. Do not shrink charts until labels become unreadable; provide a tabular data alternative.
