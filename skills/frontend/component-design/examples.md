# Component Design Examples

## Accessible Dialog

Define a controlled `open` state, labeled title, described content, close action, focus capture, focus restoration, escape behavior, and a non-modal variant boundary. Test opening, closing, validation errors, and keyboard-only use.

## Data Table

Keep sorting, filtering, pagination, loading, empty, error, and selection behavior explicit. Use semantic table structure where appropriate, provide a small-screen alternative, and avoid hiding critical columns without an accessible path.
