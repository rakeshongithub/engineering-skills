# Agent Task Decomposition

Break down large, complex engineering problems into agent-sized tasks that can be executed independently by AI coding agents.

## Quick Start

1. Read [SKILL.md](SKILL.md) for comprehensive documentation
2. Follow [instructions.md](instructions.md) for step-by-step guidance
3. See [examples.md](examples.md) for practical examples

## What This Skill Does

This skill teaches you how to:
- Break complex problems into manageable, agent-executable tasks
- Define clear task boundaries, inputs, and outputs
- Identify dependencies and parallelization opportunities
- Plan for failures and recovery
- Optimize task structure for efficient execution

## When to Use

- Complex engineering problems too large for single agent execution
- Multi-agent workflows requiring coordination
- Projects needing clear execution plans and progress tracking

## Key Outputs

- Task list with clear descriptions
- Dependency graph and execution order
- Handoff specifications
- Validation criteria
- Failure recovery strategies

## Related Skills

- **agent-workflow-design**: Orchestrate task execution
- **agent-context-engineering**: Prepare context for tasks
- **agent-instruction-design**: Create clear task instructions
