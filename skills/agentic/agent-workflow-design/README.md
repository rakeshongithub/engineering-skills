# Agent Workflow Design

Design and orchestrate multi-agent workflows that coordinate AI agents to accomplish complex engineering tasks.

## Quick Start

1. Read [SKILL.md](SKILL.md) for comprehensive documentation
2. Follow [instructions.md](instructions.md) for step-by-step guidance
3. See [examples.md](examples.md) for practical workflow examples

## What This Skill Does

This skill teaches you how to:
- Design multi-agent workflows with clear coordination
- Select appropriate workflow patterns (sequential, parallel, pipeline, etc.)
- Assign agents to tasks based on capabilities
- Design error handling and recovery strategies
- Plan monitoring and observability
- Optimize workflow execution for efficiency

## When to Use

- Complex tasks requiring multiple agents
- Coordinating specialized agents for different subtasks
- Optimizing execution through parallelization
- Ensuring reliability in multi-agent systems

## Key Outputs

- Workflow diagram showing agent coordination
- Execution plan with agent assignments
- Coordination and handoff specifications
- Error handling strategy
- Monitoring plan

## Related Skills

- **agent-task-decomposition**: Break down tasks first
- **agent-context-engineering**: Prepare context for agents
- **agent-handoff-design**: Implement handoff mechanisms
- **agent-evaluation**: Validate workflow execution
