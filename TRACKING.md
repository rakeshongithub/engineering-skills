## Quality Standards

Every skill must include:

### Required Files

- [x] **SKILL.md** - Comprehensive documentation
- [x] **skill.json** - Machine-readable metadata
- [x] **instructions.md** - Step-by-step workflow
- [x] **examples.md** - Practical examples
- [ ] **examples/** directory (if applicable)
- [ ] **evals/** directory (if applicable)

### SKILL.md Required Sections

1. Purpose (one sentence)
2. When to Use
3. When NOT to Use
4. Inputs
5. Expected Outputs
6. Workflow
7. Decision Framework
8. Quality Checklist
9. Common Mistakes
10. Examples
11. Related Skills
12. Skill Composition
13. Evaluation Criteria

### skill.json Required Fields

- name
- category
- version
- description
- inputs (array)
- outputs (array)
- requires (array)
- commonly_followed_by (array)
- alternative_to (array)
- works_with (array)
- tags (array)
- complexity (basic/intermediate/advanced)
- estimated_time
- skill_type
